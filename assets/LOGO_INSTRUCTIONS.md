# Logo Setup Instructions

## ATLAS Logo
Save the ATLAS ARCHITECTURE logo image as:
**`assets/atlas-logo.png`**

The splash screen is already configured to display it in the bottom right corner with "Powered by" text.

If the image file is not found, it will show "ATLAS ARCHITECTURE" as text fallback.

- Users first open the app
